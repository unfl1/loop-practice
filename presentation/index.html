Prompt Engineering

AI에게 어떻게 잘 시킬 것인가?

원하는 결과를 얻기 위해 역할, 목표, 제약조건, 출력 형식, 예시를 지시문 안에 설계한다.

좋은 Prompt는 한 번의 AI 호출 품질을 크게 바꾸지만, 결과 판단과 재작성은 여전히 사람에게 남는다.

사람
→
Prompt
→
AI
→
결과
결과가 마음에 들지 않으면 사람이 판단하고, 사람이 다시 프롬프트를 수정한다.

Context Engineering

AI가 판단하도록 무엇을 보여줄 것인가?

Prompt가 지시문 자체를 다룬다면, Context는 모델이 판단할 때 필요한 주변 정보를 설계한다.

정보가 부족하면 좋은 지시문이 있어도 모델은 파일, 상태, 이전 결정, 참고자료를 알 수 없다.

AI
사용자 요구이전 대화참고 문서검색 결과 메모리코드현재 상태도구 결과

질문은 “어떻게 말할까?”에서 “무엇을 보여줄까?”로 넓어진다.

Harness Engineering

AI가 어떤 환경에서 일하게 할 것인가?

Harness는 AI Agent가 실제 작업을 수행하고 결과를 확인할 수 있는 실행 무대다.

파일을 고치고, 테스트를 돌리고, 로그를 읽고, 브라우저에서 결과를 보는 행동이 가능해진다.

AI Agent
File SystemGitTestBrowser APILogsToolsPermissions

Prompt가 “무엇을 할지”를 알려준다면, Harness는 “어디서, 어떤 도구와 규칙으로 일할지”를 제공한다.

Loop Engineering

결과를 보고 AI가 다시 일하게 하려면?

Loop는 같은 작업을 무작정 여러 번 돌리는 것이 아니다.

이전 결과를 평가하고, 그 평가가 다음 실행의 입력을 바꾸도록 설계하는 구조다.

Goal
→
Generator
→
Result
→
Evaluator
→
Feedback
→
Refiner
↺
Loop Engineering은 여러 번 실행하는 것이 아니라, 이전 결과의 평가가 다음 실행의 입력을 바꾸는 구조다.

Compare

Harness Engineering vs Loop Engineering

Harness = 작업 환경

AI가 일할 수 있게 만든다

  • Tools
  • File System
  • Test / Browser / Logs
  • Permissions

Loop = 반복 과정

AI가 결과를 바탕으로 계속 개선하게 만든다

  • Evaluation
  • Feedback
  • Retry
  • Best Result
Harness 위에서 Loop가 동작한다.

Result Analysis
Loop의 장점과 한계

          

            
개선된 요소
The sketch style is simpler again, with fewer decorative eye details.
The head remains large over a smaller seated body, matching the puppy-like reference proportion.
The ears are small rounded triangles embedded near the upper head.
The overall centered pose and simple black line drawing style are preserved.

            
아직 어려운 요소
The body is still too tall and elongated compared with the compact puppy body in the reference.
The ears sit a little too high and upright compared with the lower embedded ears in the reference.
The eyes and nose feel slightly high on the face, leaving the lower face too empty.
The head outline is still taller and narrower than the soft rounded-square face in the reference.

          

          
Loop는 항상 한 방향으로 좋아지는 것이 아니다. 한 요소를 수정하면 다른 요소가 흔들릴 수 있고, Evaluator와 Feedback 설계에 따라 수렴 속도가 달라진다.

        

        
        

          

            
Conclusion

            
좋은 AI 시스템은
좋은 한 번의 답보다
좋은 반복 구조를 가진다.

          

          

            Prompt: 좋은 지시
            Context: 좋은 정보
            Harness: 좋은 환경
            Loop: 좋은 반복
